## 🤖 How I work with AI

I don't just "use ChatGPT". I run AI agents as part of a real engineering workflow:

- **Parallel agents with Orca:** I work on up to 3 projects at once, deploying Claude Code agents and subagents in isolated git worktrees, each on its own branch and dev server, with upfront planning and artifacts.
- **Context engineering:** every repo ships with an `AGENTS.md` guide, custom subagents and skills, plus architecture, domain and data-model docs so agents can work without breaking things.
- **Safeguards for generated code:** invariant tests that enforce security and business rules, type/lint/file-size ratchets, custom linters, git hooks and blocking CI gates with minimum patch coverage.
- **Real verification:** MCP integrations (Playwright, Supabase) to test features end to end in the browser before shipping.

The result: I work across 5 SaaS products at the same time, 4 of them in production.
